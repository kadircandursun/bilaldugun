# Çift fotoğrafları

Bu klasördeki `.svg` dosyaları geçici placeholder'dır.

Kendi fotoğraflarını koymak için:

1. Fotoğraflarını bu klasöre kopyala (ör. `hero.jpg`, `1.jpg`, `2.jpg` ...).
2. `lib/site.ts` içindeki `couplePhotos` ve `heroPhoto` alanlarında uzantıları
   `.svg` yerine `.jpg` (veya `.png`) yap.

- `heroPhoto`: en üstteki büyük kapak fotoğrafı (dikey/portre iyi durur).
- `couplePhotos`: alttaki galeri. `wide: true` olan foto tam genişlikte gösterilir.
